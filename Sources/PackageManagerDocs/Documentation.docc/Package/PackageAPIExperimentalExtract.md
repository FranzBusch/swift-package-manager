# swift package api experimental-extract

@Metadata {
    @PageImage(purpose: icon, source: command-icon)
}

Extract the public API of a package's Swift modules.

```
package api experimental-extract
  [--products=<products>...] [--targets=<targets>...]
  [--version] [--help]
```

Use the `api experimental-extract` command to write out the public API surface of the Swift modules in a package, as `.swiftinterface` text, to standard output. This is useful for reviewing an API, for attaching an API surface to a pull request, or for committing the API surface to a repository so that changes to it appear as a reviewable diff.

By default, every Swift module that is part of a library product is extracted. The `--products` and `--targets` options may be used to restrict the scope. Each module is preceded by a `// MARK: -` banner naming it.

The emitted interface is generated by the Swift compiler, so its exact formatting is determined by the toolchain in use rather than by the package manager. The leading metadata comments, which record the compiler version, target triple and build flags, are omitted so that the output is stable across toolchains, hosts and build configurations. Because the `experimental-` prefix indicates the command's options may still change, don't depend on its exact interface in automation yet.

This command requires the default build system.

> Note: The package is built with library evolution enabled, so that the extracted API is the resilient form that clients program against rather than one containing compiler implementation details. Because of this, the build performed by this command is separate from an ordinary `swift build`, and extraction can fail for packages that cannot be built with library evolution.

- term **--products=\<products\>**:

*One or more products to include in the extracted API. If present, only the specified products (and any targets specified using `--targets`) will be extracted.*


- term **--targets=\<targets\>**:

*One or more targets to include in the extracted API. If present, only the specified targets (and any products specified using `--products`) will be extracted.*


- term **--version**:

*Show the version.*


- term **--help**:

*Show help information.*

## Examples

Review the whole public API of a package:

```bash
swift package api experimental-extract
```

Write the API surface to a file, for committing alongside the source:

```bash
swift package api experimental-extract > API.swiftinterface
```

Extract a single module:

```bash
swift package api experimental-extract --targets MyLibrary
```
